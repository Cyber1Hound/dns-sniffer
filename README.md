# DNS Sniffer & Amplification Tool

A lightweight Docker image for DNS sniffing and amplification testing, built on Ubuntu 20.04 with `dnsutils`.

## Docker Hub Image

Docker Image Available: [dralqarni/dns-sniffer on Docker Hub](https://hub.docker.com/r/dralqarni/dns-sniffer)


## How to Use

```bash
docker pull dralqarni/dns-sniffer:latest
docker run --rm dralqarni/dns-sniffer:latest
